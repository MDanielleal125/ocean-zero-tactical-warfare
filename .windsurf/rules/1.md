Project: BattleShip Web
Tech Stack:
- HTML
- CSS
- JavaScript ES6 Modules
- GitHub

==================================================
CORE RULE
==================================================

Never create your own architecture.

Follow strictly the existing project structure, naming conventions, contracts and patterns.

Do not reorganize folders.
Do not rename existing files.
Do not invent new systems.
Do not replace existing logic unless explicitly requested.

==================================================
LANGUAGE RULES
==================================================

All code must be written in English.

Never mix:

BAD:

jugadorBoard
tableroEnemy

GOOD:

playerBoard
enemyBoard

==================================================
NAMING RULES
==================================================

Use camelCase only.

Examples:

playerBoard
enemyBoard
currentTurn
selectedShip
enemyShips

==================================================
OFFICIAL NAMES
==================================================

Use ONLY these names:

playerBoard
enemyBoard

playerMatrix
enemyMatrix

shot
hitCell
missCell

currentTurn
winner
gameStarted

placeShip()
shootCell()
validateShipPlacement()
checkWinner()

computerAI

Never replace them.

Forbidden:

playerGrid
enemyGrid
verifyWinner
attackCell

==================================================
FUNCTION RULES
==================================================

Functions must follow:

verb + noun

Allowed:

createBoard()
renderShips()
shootCell()
validatePosition()
checkWinner()

Forbidden:

run()
data()
test()
execute()
check()

==================================================
SINGLE RESPONSIBILITY RULE
==================================================

Each function:

- does one thing only
- should stay small
- must have descriptive names
- should avoid hidden dependencies
- should avoid duplicated logic

==================================================
FILE RESPONSIBILITY RULE
==================================================

Each file has one purpose only.

Example:

boardManager.js
→ board logic

shootingSystem.js
→ shooting logic

winnerSystem.js
→ victory logic

renderBoard.js
→ UI rendering

notifications.js
→ visual messages

Never create giant files.

Forbidden:

battle.js
4000+ lines

==================================================
GLOBAL VARIABLES
==================================================

Do NOT create new globals.

Forbidden:

window.board
window.turn
window.game

Everything must go through:

gameState.js

==================================================
GAME STATE RULE
==================================================

Game state only exists inside:

gameState.js

Structure:

export const gameState = {

currentTurn:'player',
gameStarted:false,
winner:null,

playerBoard:[],
enemyBoard:[],

playerShips:[],
enemyShips:[]

};

Never duplicate state elsewhere.

==================================================
CONSTANT RULE
==================================================

All fixed values belong in:

constants.js

Example:

export const BOARD_SIZE=10;

export const CELL_STATES={

EMPTY:'empty',
SHIP:'ship',
HIT:'hit',
MISS:'miss'

};

Never hardcode repeated values.

==================================================
MODULE RULES
==================================================

Use ES6 modules only.

Always:

export
import

Never use:

require()

Never use inline scripts.

==================================================
DUPLICATION RULE
==================================================

Never duplicate logic.

Forbidden:

checkWinner()
validateWinner()
verifyWinner()

for the same purpose.

Reuse existing functions.

==================================================
UI RULES
==================================================

Never use:

alert()

Use:

- modal
- notification
- UI message
- visual feedback component

==================================================
DATA STRUCTURE RULES
==================================================

Cell:

{
row:0,
col:0,
state:'empty'
}

Ship:

{
id:'carrier-1',
type:'carrier',
size:5,
health:5,
direction:'horizontal',
positions:[]
}

Shot:

{
row:4,
col:6,
result:'hit'
}

Do not modify structures.

Follow:

↓

↓

↓

Finish game
