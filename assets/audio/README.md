# Audio Assets

Coloca aqui los archivos de musica para cada escena del juego.

Archivos esperados (configurados en `js/core/constants.js`):

| Escena   | Archivo              |
|----------|----------------------|
| MENU     | menu-theme.mp3       |
| LOBBY    | lobby-theme.mp3      |
| BATTLE   | battle-theme.mp3     |
| VICTORY  | victory-theme.mp3    |
| DEFEAT   | defeat-theme.mp3     |

Formatos soportados: `.mp3`, `.ogg`, `.wav`

Para cambiar las rutas, edita el objeto `SCENE_MUSIC` en `js/core/constants.js`.
